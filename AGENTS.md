# AGENTS.md

Instructions for AI coding agents working in this repository. People will find them useful too.

## Commands

```sh
make init-dev     # install the package and the development tools into the active environment
make format       # apply black and isort
make checks       # every check CI runs, in CI's order; run it before you say a change is done
make man          # rebuild the man page and the packaged manual after editing docs/MANUAL.md
make build        # wheel and sdist into build/dist
```

Use Python 3.15 for development; the package supports 3.14 and later.

## Layout

```text
src/python_template/        the package; py.typed marks it as typed
src/python_template/cli.py  the command line, one cmd_* function per command
src/python_template/data/   MANUAL.md and python-template.1, generated by make man, never edited by hand
docs/MANUAL.md              the one source for the guide and the man page
tests/python_template/      pytest tests, mirroring the package
scripts/                    build_man.py and the one time rename.py
```

## Rules the checks enforce

- mypy runs in strict mode: every function has full type hints, and `Any` needs a reason.
- Docstrings use the Sphinx style (`:param name:`, `:returns:`, `:raises:`) and darglint checks they match the
  signature. Tests are exempt.
- Imports are absolute; flake8 rejects relative imports.
- Lines are at most 120 characters, in every file type, including Markdown.
- bandit fails on shell injection and similar; a justified exception carries `# nosec <code>: <reason>`.

## Conventions the checks cannot see

- Every command takes `--json` and prints one object with stable fields. Exit 0 on success, 2 on bad arguments.
- When a command or option changes, update `docs/MANUAL.md` in the same commit and run `make man`.
- Add an entry to `CHANGELOG.md` for anything a user would notice.
- The version comes from the git tag through setuptools_scm. Tags carry the bare version, `1.2.0`, never `v1.2.0`.
- Never commit secrets, `.env` files or anything from `build/`.
